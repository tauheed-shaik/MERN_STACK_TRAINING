# Day 9 - Shadows, Lists, Overflow, and Positioning

## Overview
This folder introduces some advanced CSS properties that improve layout and visual design. The files show how to add shadows, style lists, control overflow, and position elements on the page.

## File: index1.html
This file demonstrates:
- `box-shadow` for adding depth to a box
- `text-shadow` for styling text with shadow effect

## File: index2.html
This file shows how to style lists using CSS.
- `list-style-type` changes the bullet style.
- `list-style-position` decides whether bullets appear inside or outside the content.
- `list-style` can combine several list properties.

## File: index3.html
This file teaches the `overflow` property.
- `overflow: auto` adds scrollbars only when needed.
- `overflow-x` and `overflow-y` can control horizontal and vertical overflow separately.

## File: index4.html
This file introduces CSS positioning.
- `position: sticky` keeps an element fixed while scrolling.
- `position: relative` moves an element from its original position.
- `position: fixed` keeps an element pinned to the viewport.
- `position: absolute` can place an element relative to a positioned parent.

## File: practice.html
This is a blank exercise file where students can practice creating their own layout or CSS experiment.

## Learning Outcome
Students should understand how to add visual effects, manage overflow, and position elements with greater control in a webpage.
