# Day 2 - HTML, CSS, and JavaScript Basics

## Overview
This folder introduces the basic relationship between HTML, CSS, and JavaScript. It shows how a webpage can be styled and how a simple script can be connected to it.

## File: index.html
This file is a simple introductory webpage.
- It uses multiple heading levels from `<h1>` to `<h6>`.
- A paragraph is added with `<p>`.
- The page links to an external stylesheet using `<link rel="stylesheet" href="style.css">`.
- The JavaScript file is connected using `<script src="index.js"></script>`.

## File: bookmark.html
This file demonstrates a simple hyperlink example.
- It contains a paragraph with a link to a website.
- It teaches how anchors work in HTML.

## File: style.css
This file shows the first steps in CSS.
- `body` styles the whole page background color and text color.
- `p` styles paragraph backgrounds.

## File: index.js
This file contains a very simple JavaScript line:
- `prompt("Are you ok ?")`
- It introduces the idea that JavaScript can interact with users through a popup prompt.

## Key Learning Points
- HTML defines the page content.
- CSS controls the appearance.
- JavaScript adds behavior and interactivity.
- A webpage is usually built from three layers: structure, style, and logic.

## Learning Outcome
Students should be able to connect HTML, CSS, and JavaScript in a simple web page and understand the purpose of each file.
