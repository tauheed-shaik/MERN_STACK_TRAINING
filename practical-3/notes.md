# Day 3 - Images, Lists, Tables, and Media

## Overview
This folder focuses on content organization. It shows how students can present information using images, definition lists, ordered and unordered lists, tables, and media elements.

## File: image-lists.html
This is a comprehensive HTML practice file.

### 1. Images
The page uses `<img>` to display images. Students learn:
- how to add images with the `src` attribute
- how to provide alternative text with `alt`
- how to control size using `height` and `width`

### 2. Definition List
The file uses `<dl>`, `<dt>`, and `<dd>` to create a definition list. This is useful for showing terms and their meanings.

### 3. Unordered and Ordered Lists
The page demonstrates:
- `<ul>` for bullet points
- `<ol>` for numbered items
- the `type` attribute to change the bullet style

### 4. Tables
A table is created using:
- `<table>`
- `<thead>`, `<tbody>`, and `<tfoot>`
- `<tr>`, `<th>`, and `<td>`

This teaches students how data can be displayed in rows and columns.

### 5. Video and Audio
The page also includes `<video>` and `<audio>` tags. These are used to embed multimedia content with the `controls` attribute.

## File: style.css
The CSS file adds a simple border to table cells using:
- `td, th { border: 1px solid black; }`

## Learning Outcome
Students should be able to structure content clearly using lists, tables, media, and images in an HTML page.
