# Cat photo app - First Web Page with HTML

## Overview
This folder is the first practical example of creating a complete webpage using HTML. The file shows how a simple website can be built using semantic structure, links, images, lists, and a footer.

## File: index.html
The page begins with a basic HTML document structure:
- `<!DOCTYPE html>` tells the browser that the document is an HTML5 file.
- `<html>` is the root element of the page.
- `<head>` contains metadata such as the page title.
- `<body>` contains everything visible to the user.

## Important Concepts Covered
### 1. Page Structure
The page uses:
- `<main>` for the main content area
- `<section>` to divide content into meaningful blocks
- `<h1>` and `<h2>` for headings
- `<p>` for paragraphs

### 2. Links and Images
The project demonstrates how to:
- create hyperlinks using `<a>`
- open external links
- add images with `<img>`
- wrap an image inside a link so it becomes clickable

### 3. Lists
The page uses:
- `<ul>` for unordered lists
- `<ol>` for ordered lists
- `<li>` for each list item

### 4. Semantic Content and Footer
The file also introduces:
- `<figure>` and `<figcaption>` for image captions
- `<em>` and `<strong>` for emphasized text
- `<footer>` for the closing section of the page

## Learning Outcome
By the end of this lesson, students should understand how to build a simple but well-structured webpage using basic HTML tags and content organization.
