# practical-4 - Forms, SVG, and Embedded Content

## Overview
This folder is about practical HTML elements beyond basic text and images. It introduces forms, input controls, SVG graphics, and embedded external content.

## File: index.html
This is a basic form page.
- `<form>` is used to collect user input.
- `<label>` is attached to form fields for clarity.
- `<input>` is used with different types such as text, radio, checkbox, and submit.
- `<textarea>` allows multi-line text input.
- `<select>` and `<option>` create dropdown menus.

## File: index2.html
This file shows a more complete registration form.
- It uses `required` validation.
- The `type="email"` field helps validate email input.
- `type="password"` is used for secure input.
- `type="tel"` and `pattern` are used for phone numbers.

## File: index3.html
This file demonstrates:
- SVG shapes like circles and rectangles
- `<iframe>` for embedding external web pages or videos

This introduces students to the idea that HTML can display graphics and embedded content directly inside a webpage.

## Learning Outcome
Students should be able to create simple forms, collect user input, and embed external media or graphical content in web pages.
