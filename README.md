# MERN Stack Training Repository

This repository is made for students. It is a learning space where you can study, revise, and practice the concepts taught during the training sessions.

## Who This Repository Is For
- Students who are learning web development
- Beginners who want to understand HTML, CSS, JavaScript, and frontend basics
- Learners preparing for MERN stack training step by step

## What This Repository Contains
- Simple beginner-friendly notes for each training session
- Practical HTML files for hands-on learning
- Organized folders for each day/session
- A clear path from basic web development to future MERN stack topics

## How Students Should Use This Repo
1. Read the notes in the folder for the day you are learning.
2. Open the related practical files and study how the code works.
3. Try to recreate the examples on your own.
4. Practice regularly so the concepts become clear.

## Learning Journey
This repository helps students build a foundation in:
- HTML structure and content creation
- CSS styling and page layout
- JavaScript basics
- Creating simple webpages and multi-page projects
- Understanding practical web development exercises

## What Comes Next
After completing these basics, students can move forward to:
- JavaScript in depth
- React basics
- Node.js and Express
- MongoDB and full-stack development
