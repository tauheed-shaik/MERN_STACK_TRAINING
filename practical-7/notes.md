# Day 7 - Colors, Box Model, and Fonts

## Overview
This folder teaches the visual side of CSS. It introduces how colors are represented, how boxes are built in CSS, and how fonts and text styling are controlled.

## File: colors.html
This file explains different ways to write colors in CSS:
- color keywords
- hex colors
- RGB values
- RGBA values
- HSL and HWB values

Students learn that color is one of the most important ways to make a webpage attractive and readable.

## File: index.html
This file introduces the CSS box model.
- `padding` creates space inside an element.
- `margin` creates space outside an element.
- `border` creates a visible outline.
- `height` and `width` control the size of the box.
- `box-sizing: border-box;` ensures the total size includes padding and border.

## File: index2.html
This file demonstrates font styling.
- `font-family` changes the text style.
- `font-size` adjusts the text size.
- `font-weight` makes text bold or lighter.
- `text-align`, `text-transform`, `text-decoration`, and `text-indent` control text placement and decoration.

It also uses an imported Google font to show that external fonts can be applied to a webpage.

## File: practice.html
This file acts as a challenge page where students can apply their understanding of CSS styling to a paragraph inside a container.

## Learning Outcome
Students should understand how to change visual appearance using colors, spacing, borders, and text styling.
