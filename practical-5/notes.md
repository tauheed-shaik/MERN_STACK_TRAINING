# practical-5 - Semantic Tags, Entities, and Styling Basics

## Overview
This folder combines layout, semantic structure, text formatting, and CSS styling. It is one of the most important folders for understanding how webpages are organized and made visually attractive.

## File: index1.html
This page demonstrates semantic HTML elements.
- `<header>` is used for the top section of the page.
- `<nav>` contains navigation links.
- `<main>` wraps the main content.
- `<footer>` is used for the bottom section.

It also shows how pages can link to each other using anchor tags.

## File: aboutus.html
This is a simple standalone page that teaches how a separate page can be created and linked from the navigation.

## File: contactus.html
This file is another simple page used to represent a contact section of a website.

## File: index2.html
This file introduces HTML entities and code display.
- `&lt;` and `&gt;` are used to display angle brackets.
- `&copy;` displays the copyright symbol.
- `<pre>` preserves whitespace and line breaks.
- `<code>` is used to display code snippets.

## File: index3.html
This file shows how CSS can be written inline as well as linked externally.
- Inline styles are applied directly to the `<h1>` tag.
- The page uses `<div>` and `<span>` to show differences in block-level and inline elements.

## File: style1.css
This external stylesheet introduces:
- background color for the whole page
- background images
- styling for headings

## Learning Outcome
Students should understand semantic structure, HTML entities, and how CSS can be applied using inline styles and external stylesheets.
