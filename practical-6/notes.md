# Day 6 - CSS Selectors

## Overview
This folder focuses on CSS selectors, which are the rules used to target HTML elements and apply styling to them.

## File: index.html
This file introduces basic selectors:
- element selector: `h1`
- id selector: `#green`
- class selector: `.bg-yellow`

It teaches that each selector targets a different type of HTML element or attribute.

## File: index2.html
This file explains more advanced CSS selectors:
- child selector: `div > p`
- descendant selector: `div h3`
- universal selector: `*`
- pseudo-classes such as `:hover`, `:visited`, `:link`, and `:active`

These selectors are important because they help developers style specific elements based on structure and state.

## File: style.css
This file is empty, which is a useful reminder that CSS files can be created and filled later depending on the project needs.

## Learning Outcome
Students should be able to identify and use different CSS selectors to style elements precisely in a webpage.
