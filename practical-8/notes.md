# practical-8 - Specificity, Units, and Display Properties

## Overview
This folder focuses on CSS behavior and layout control. It explains how CSS rules are prioritized, how size values work, and how elements are displayed.

## File: index.html
This file introduces CSS specificity.
- An element can have multiple classes and IDs.
- CSS uses specificity rules to decide which style will be applied when there are conflicts.

## File: index2.html
This file explains CSS sizes and values.
- `vw` and `vh` are viewport-based units.
- `em` is relative to the font size.
- `width: 80vw` makes the element take 80% of the viewport width.
- `min-height` ensures the container remains at least a certain height.

This lesson helps students understand responsive design basics and flexible sizing.

## File: index3.html
This file demonstrates the CSS `display` property.
- `display: inline-block` allows elements to behave like blocks but stay inline.
- `display: none` hides an element completely.
- `visibility: hidden` hides an element but keeps its space in layout.

## Learning Outcome
Students should be able to understand CSS prioritization, choose effective unit values, and control how elements appear on the page.
